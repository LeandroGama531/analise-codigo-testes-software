# 🔍 Análise de Código e Testes de Software

## 📌 Sobre o Projeto

Projeto acadêmico com foco em análise de código fonte e validação de testes em um sistema de gestão de vendas (CRUD API).

## 🚀 Objetivos

* Validar funcionamento do sistema
* Identificar falhas e vulnerabilidades
* Testar integração entre front-end e back-end

## 🧪 Metodologia

* Teste de Caixa Branca (análise do código)
* Teste de Caixa Preta (testes funcionais)
